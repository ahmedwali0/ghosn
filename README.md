# غُصن — زيت زيتون من مزرعتنا

ستور بسيط على GitHub Pages. الطلبات بتتسجل في Google Sheet، ومن الشيت بتتبعت لبوسطة.

## الملفات
- `index.html`: الستور
- `config.js`: فيه رابط شيت الطلبات (Web App من Google Apps Script)
- ملفات jpg و mp4: صور وفيديوهات المزرعة

## تغيير السعر أو مصاريف الشحن
مش محتاج تعدّل الكود. غيّر من الشيت:
- الأحجام والأسعار وسعر الافتتاح: تاب **المنتجات**
- آخر يوم في سعر الافتتاح وأرقام التحويل وإيقاف الطلبات: تاب **الإعدادات**
- مصاريف الشحن ومدة التوصيل لكل محافظة: تاب **الشحن**

الستور بيقرا القيم الجديدة أول ما حد يفتح الصفحة.
